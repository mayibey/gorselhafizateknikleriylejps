## Önce şunu okuyun: mevzuat dilinin sözlüğü

Kanun metinleri günlük Türkçeyle yazılmaz. Aşağıdaki kelimeler kitabın her yerinde geçiyor. Bir satırı anlamadığınızda buraya dönün.

### Ceza hukukunun temel kelimeleri

| Terim | Günlük dille ne demek |
|---|---|
| **Fail** | Suçu işleyen kişi. |
| **Mağdur** | Suçtan zarar gören kişi. |
| **Kast** | Bilerek ve isteyerek yapmak. "Vuracağım" deyip vurmak. |
| **Olası kast** | "Olursa olsun" demek. Sonucu isteyerek değil ama olabileceğini görüp yine de yapmak. Kalabalığa doğru araba sürmek gibi. |
| **Taksir** | Dikkatsizlik, ihmal. Sonucu hiç düşünmeden yapmak; kırmızı ışıkta dalgınlıkla geçip birine çarpmak. |
| **Bilinçli taksir** | Sonucu görmek ama "bana bir şey olmaz" deyip yapmak; olunca da istememiş olmak. Hızlı giderken "çarpmam" diye düşünüp çarpmak. |
| **Teşebbüs** | Suça başlayıp elinde olmayan bir sebeple tamamlayamamak. Kasayı açmaya çalışırken yakalanmak. |
| **İştirak** | Suça birden fazla kişinin katılması. |
| **Müşterek fail** | Suçu birlikte, iş bölümü yaparak işleyenlerin her biri. Hepsi asıl suçlu sayılır. |
| **Azmettiren** | Suçu başkasına işleten, aklına sokan kişi. Ceza olarak asıl fail gibi sorumlu olur. |
| **Yardım eden** | Suçun işlenmesine yardımcı olan; cezası asıl failden azdır. |
| **İçtima** | Birden çok suçun bir arada nasıl cezalandırılacağı. |
| **Zincirleme suç** | Aynı kararla, aynı suçu değişik zamanlarda birden çok kez işlemek. Tek ceza verilir ama artırılır. |
| **Fikri içtima** | Tek hareketle birden çok suç işlemek. En ağır suçtan ceza verilir. |
| **Hukuka uygunluk sebebi** | Fiili suç olmaktan çıkaran durum: meşru savunma, kanunun emri, ilgilinin rızası gibi. |
| **Meşru savunma (meşru müdafaa)** | Kendine veya başkasına yönelen haksız saldırıyı savmak için zorunlu ölçüde karşılık vermek. |
| **Zorunluluk hâli** | Başka çıkar yol yokken, ağır bir tehlikeden korunmak için suç işlemek. |
| **Haksız tahrik** | Haksız bir davranış yüzünden öfkelenip suç işlemek; ceza indirilir. |
| **Kusurluluk** | Kişinin yaptığından sorumlu tutulabilme hâli. Akıl hastalığı, yaş küçüklüğü gibi durumlar kusurluluğu etkiler. |

### Ceza türleri ve süreler

| Terim | Günlük dille ne demek |
|---|---|
| **Ağırlaştırılmış müebbet hapis** | En ağır ceza. Ömür boyu, sıkı güvenlik rejiminde. |
| **Müebbet hapis** | Ömür boyu hapis; ağırlaştırılmışa göre koşulları daha hafif. |
| **Süreli hapis** | Belirli yıl olarak verilen hapis. |
| **Adli para cezası** | Mahkemenin verdiği, gün sayısı üzerinden hesaplanan para cezası. |
| **İdari para cezası** | Mahkeme değil, idarenin (vali, kaymakam, kolluk gibi) kestiği para cezası. |
| **Güvenlik tedbiri** | Ceza değil, korunma amaçlı tedbir: eşyanın müsaderesi, tedavi gibi. |
| **Müsadere** | Suçta kullanılan veya suçtan elde edilen eşyaya devletin el koyması. |
| **Zamanaşımı** | Süre dolunca soruşturmanın veya cezanın düşmesi. |
| **Tekerrür** | Daha önce ceza almış kişinin yeniden suç işlemesi; ceza ağırlaşır. |

> **"X yerine Y" ne demek?** Kitapta "ağırlaştırılmış müebbet yerine müebbet, müebbet yerine 20-25 yıl" gibi cümleler göreceksiniz. Okunuşu şudur: *Suçun normal cezası ağırlaştırılmış müebbetse, bu durumda ceza müebbete iner; normal ceza müebbetse 20-25 yıl hapse iner.* Yani suçun kendi cezası neyse, o durumda bir basamak aşağı (veya yukarı) gider.

### Yolsuzluk suçlarının farkı (sınavda hep karıştırılır)

| Suç | Farkı tek cümlede |
|---|---|
| **Zimmet** | Görevi gereği kendisine teslim edilmiş parayı/malı kendine mal etmek. |
| **İrtikâp** | Görevin verdiği nüfuzu kullanarak kişiyi menfaat sağlamaya **zorlamak** (icbar) veya ikna etmek. |
| **Rüşvet** | Görevle ilgili bir iş için kişiyle **anlaşarak** menfaat sağlamak. Anlaşma yeterlidir. |
| **Nüfuz ticareti** | İş halledeceğim diye kendisine menfaat sağlamak; aslında etkisi olsun olmasın. |
| **Görevi kötüye kullanma** | Yukarıdakilere girmeyen, görevin gereğine aykırı davranış. |

### İdare ve kolluk kelimeleri

| Terim | Günlük dille ne demek |
|---|---|
| **Mülki amir** | İlde vali, ilçede kaymakam. "Mülki amir" denince bu ikisinden biri kastedilir. |
| **Mülki idare amiri** | Aynı anlam. |
| **Kolluk** | Jandarma, polis, sahil güvenlik gibi güvenlik güçleri. |
| **Adli kolluk** | Suç işlendikten sonra savcı emrinde çalışan kolluk. |
| **Önleme kolluğu** | Suç işlenmeden önce önlem alan kolluk. |
| **Resen** | Kendiliğinden; şikâyet beklemeden. |
| **Tüzel kişi** | Şirket, dernek, vakıf gibi kurum. İnsan olmayan "kişi". |
| **Gerçek kişi** | İnsan. |
| **İlgili kişi** | Kişisel verisi işlenen kişi. |
| **Muhatap** | Yazının gönderildiği kurum veya kişi. |
| **Tebligat** | Resmî bildirimin usulüne uygun ulaştırılması. |
| **Tebliğ** | Bildirmek, ulaştırmak. |
| **Zilyet** | Bir şeyi fiilen elinde bulunduran kişi (sahibi olmak şart değil). |
| **Hükmi şahsiyet** | Tüzel kişilik. |
| **İdari yaptırım** | İdarenin verdiği ceza (para cezası, mühürleme gibi). |
| **Genelge** | Bir makamın alt birimlere gönderdiği uygulama talimatı. |
| **Yönetmelik** | Kanunun nasıl uygulanacağını gösteren ayrıntılı düzenleme. |
| **Yönerge** | Kurum içi, daha ayrıntılı uygulama kuralı. |

### Askerî ve personel kelimeleri

| Terim | Günlük dille ne demek |
|---|---|
| **Muvazzaf** | Kadrolu, sözleşmeli olmayan asker. |
| **Sözleşmeli subay/astsubay** | Belirli süreli sözleşmeyle çalışan personel. |
| **Nasıp** | Rütbeye atanma tarihi. Kıdem bu tarihe göre hesaplanır. |
| **Kıdem** | Rütbedeki eskilik sırası. |
| **Sicil** | Personelin yıllık değerlendirme notu. |
| **Disiplin amiri** | Personele disiplin cezası verebilen üstü. |
| **Disiplin kurulu** | Ağır cezaları görüşen kurul. |
| **Uyarma / kınama** | En hafif iki disiplin cezası (yazılı ikaz). |
| **Aylıktan kesme** | Maaştan belirli oranda kesinti cezası. |
| **Kademe ilerlemesinin durdurulması** | Terfi sırasının bir süre dondurulması. |
| **Meslekten çıkarma** | Kamu görevine son verilmesi, en ağır disiplin cezası. |
| **Görevden uzaklaştırma** | Soruşturma sürerken geçici olarak görevden alma; ceza değildir. |
| **Mecburi hizmet** | Okuduğu veya eğitim aldığı için devlete çalışma zorunluluğu. |
| **İstihdam** | Çalıştırma, görevlendirme. |

### Resmî yazışma kelimeleri

| Terim | Günlük dille ne demek |
|---|---|
| **Üstveri** | Belgenin künye bilgisi: kimden, kime, tarih, sayı gibi. Belgenin ayrılmaz parçasıdır. |
| **DETSİS** | Devlet teşkilatının numara sistemi; her kurumun bir numarası var. |
| **Paraf** | Küçük imza, onay işareti. |
| **Tekit** | Cevap gelmeyince yazılan hatırlatma yazısı. |
| **İlgi** | Yazının hangi önceki yazıya dayandığını gösteren bölüm. |
| **Arz / rica** | Üste yazarken "arz ederim", asta yazarken "rica ederim". |
| **e-Yazışma Teknik Rehberi** | Elektronik yazışmanın teknik kurallarını belirleyen resmî rehber. |
| **Güvenli elektronik imza** | Islak imza ile aynı hukuki sonucu doğuran elektronik imza. |

> **Sınav taktiği:** Bu kitaptaki her satırın sonunda *Tuzak:* yazan kısım, sınavın o hükmü nasıl çarpıtacağını gösterir. Soruda bir şık "neredeyse doğru" görünüyorsa, tuzak satırında anlatılan değişikliklerden biri yapılmış olabilir: bir sayı komşusuyla değiştirilmiş, bir makam başkasıyla değiştirilmiş, "en az" yerine "en çok" yazılmış ya da maddede olmayan bir şart eklenmiş olabilir.
